# Security policy

The card runs in the Home Assistant frontend with the rights of the logged-in
user and reads entity states and history. Please report a flaw privately: use
**Report a vulnerability** on the repository's
[Security tab](https://github.com/naqoyqatsi83/lan-flow-card/security/advisories/new)
instead of opening a public issue.

Include the card version, the Home Assistant version, and the steps or config
that trigger it. Only the latest release is fixed; there are no backports.

Vulnerabilities in Home Assistant itself belong to the
[Home Assistant project](https://www.home-assistant.io/security/).
